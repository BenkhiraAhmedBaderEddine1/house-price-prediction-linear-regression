<h2 align="center">✦ THE INTELLIGENCE BEHIND EVERY PROPERTY ✦</h2>

**OBSIDIAN ESTATES AI** is a machine learning project that predicts residential house prices using property characteristics and relevant housing data from the USA_Housing dataset.

By combining exploratory data analysis, feature preparation, standardization, and Linear Regression, the project demonstrates how historical housing data can be transformed into meaningful price estimates.

The mission is simple: turn raw data into clear, interpretable real estate insights.

<h2 align="center">◈ PERFORMANCE METRICS ◈</h2>

- **R² Score** — measures the proportion of target variance explained by the model.
- **Mean Absolute Error (MAE)** — measures the average absolute prediction error.
- **Mean Squared Error (MSE)** — measures the average squared prediction error.

These complementary metrics provide a clearer picture of predictive performance than a single score alone.
